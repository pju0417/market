# PRODUCT_SPEC.md

## 목표

초등학생을 주 대상으로 하는 **시장경제 체험형 교육 게임**. 학생이 교실에서 직접 플레이하며
생산자(기업)·판매자(가게)·소비자(가계)의 관점을 모두 경험하고, 가격·품질·비용·경쟁·수요와
공급을 몸으로 이해하게 하는 것이 목적이다.

## 대상 사용자

- **학생**: 게임의 플레이어. 매 라운드 기업/가게/가계 세 역할을 모두 수행한다.
- **교사**: 게임 세션을 운영하고 라운드 진행, 결과 확인을 담당한다. 장기적으로는 자신의 Google
  계정/Drive만으로 별도 서버 비용 없이 게임을 운영할 수 있어야 한다 ([GOOGLE_SHEETS_ARCHITECTURE.md](GOOGLE_SHEETS_ARCHITECTURE.md)).

## 핵심 경험

1. 학생 1명은 **기업 + 가게 + 가계**를 동시에 소유한다 (역할 분리, 자산·손익 분리는
   [GAME_RULES.md](GAME_RULES.md) 참고).
2. 매 라운드 전원이 같은 역할을 동시에 수행한다 (기업 턴 → 가게 턴 → 가계 턴). 특정 학생이
   다른 학생을 기다리는 구조를 만들지 않는다.
3. 기업의 상품은 자동으로 가게에 가지 않는다 — 도매시장에서 가게가 직접 비교하고 선택한다.
4. 가게의 상품도 가계가 직접 비교하고 선택한다.
5. 소규모 학급에서도 시장이 정상적으로 형성되도록 부족한 참여자는 NPC가 규칙 기반으로 보충한다.
6. 기본 진행은 7라운드이며, 라운드가 진행될수록 확장(신상품/설비/신규 점포), 경쟁 전략(가격/
   품질/전문화/광고), 시장 변화(원자재/유행/소득/지역)를 순차적으로 경험한다
   ([ROUND_FLOW.md](ROUND_FLOW.md)).
7. 학생은 매 턴 규칙 기반 전략 비서로부터 현재 상황 설명과 2~3개의 전략 선택지(장단점 포함)를
   받을 수 있다. 비서는 정답을 지시하거나 미래를 확정적으로 예측하지 않는다
   ([ADVISOR_RULES.md](ADVISOR_RULES.md)).

## 교육 목표

- 생산자/판매자/소비자 세 관점을 한 사람이 모두 경험하게 하여 시장경제의 상호작용을 체득시킨다.
- 가계의 목표를 "돈을 많이 남기는 것"으로 단순화하지 않고, 소비 만족·필요 충족·예산 관리를
  함께 고려하게 한다.
- 특정 전략(업종, 상권, 가격 정책 등)이 항상 압도적으로 유리하지 않도록 하여, 다양한 전략적
  선택이 의미를 갖게 한다 (검증 기준은 [ECONOMY_ENGINE.md](ECONOMY_ENGINE.md) 및
  `economy-reviewer` 에이전트 참고).

## 이번 단계(Milestone 0)의 산출물 범위

이번 초기 구축 단계는 게임 자체를 구현하지 않는다. 산출물은 프로젝트 구조, 설계 문서, 개발
규칙(CLAUDE.md), 역할별 subagent, 테스트/시뮬레이션 자동화 기반, TypeScript 프로젝트 초기화다.

## 장기 배포 목표

다른 교사도 별도 유료 서버 없이 사용할 수 있어야 한다. 공통 프런트엔드 + 교사별 Apps Script +
교사별 Google Sheet의 분산 저장 구조를 목표로 하며, 경제 계산은 항상 TypeScript/JavaScript
엔진에서 수행하고 Google Sheet는 순수 저장소로만 쓴다 ([GOOGLE_SHEETS_ARCHITECTURE.md](GOOGLE_SHEETS_ARCHITECTURE.md)).
