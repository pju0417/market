# ADVISOR_RULES.md

## 원칙

플레이어 전략 비서는 **생성형 AI API를 사용하지 않는다.** 게임 데이터와 사전에 정의된 분석
규칙만 사용한다. 학생의 자유 질문 응답 기능은 현재 범위에서 제외한다.

비서의 행동 원칙:

- 정답을 직접 지시하지 않는다.
- 미래 결과를 확정적으로 예측하지 않는다.
- 현재 상황을 설명한다.
- 원인 후보를 제시한다.
- 2~3가지 전략 선택지를 제공하며, 각 선택지의 장점과 위험을 함께 알려준다.
- 최종 결정은 학생에게 맡긴다.

## 턴별 분석 대상 (참고 지표, 구체 로직은 미구현)

### 기업 턴
판매율, 재고율, 도매가격, 시장 평균가격, 품질, 시장 평균품질, 생산량, 순이익, 이익률,
시장점유율, 유통비, 업종 확장 가능성.

### 가게 턴
재고, 품절 여부, 판매가격, 도매 매입가격, 마진, 공급처 의존도, 상권 적합성, 전문성,
경쟁 밀도, 임대료 부담, 유통비.

### 가계 턴
예산, 소비 비율, 필수 소비, 만족도, 저축, 가격/품질 선호.

가게 턴 비서는 `AdvisorRules.specialtyFocusMinRound`(기본값 5) 이상 라운드부터, 이미
매 라운드 알려주던 "지금 전문 업종 안/밖" 사실 문장과 별개로 전문화 유지/이탈이 그 자체로
하나의 경쟁 전략 축이라는 안내 문장을 추가한다(방향 지시 없이 유지/이탈 각각의 사실만
전달). 같은 방식으로 `competitionFocusMinRound`(기본값 5)는 기업·가게 턴에 가격/품질 경쟁
안내 문장을 추가한다.

## 설계 요구사항

- 전략 분석 규칙은 플레이테스트를 통해 조정 가능해야 한다. **임계값을 코드에 하드코딩하지
  않고** 설정값 또는 규칙 데이터(JSON/TS 상수 모듈 등)로 분리해 관리한다.
- 비서 로직은 `src/advisor/`에 위치하며, 경제 엔진(`src/economy`)이 계산한 상태를 입력으로
  받아 텍스트/선택지 형태의 출력을 생성하는 순수 함수 형태를 지향한다 (UI에 비종속).
