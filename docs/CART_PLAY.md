# 장바구니와 명시적 턴 종료 (2026-09-30)

사용자 요청: 우선순위 구매 대신 장바구니에 담아 결제하고, 모두가 턴 종료를 누를 때까지 각 역할의 활동을 계속한다. Google Sheets / Apps Script 배포 구조를 유지한다.

## 학생의 활동

- 기업 활동 ① 생산: 생산 계획을 정하고 `생산 계획 확정 · 턴 종료`를 누른다. 전원 종료 후 생산·도매시장 갱신을 실행한다.
- 기업 활동 ② 매입·판매: 상품을 비교해 장바구니에 담고 `장바구니 결제`를 누른다. 성공한 거래는 즉시 반영되며 같은 턴에 다시 구매할 수 있다. 판매 가격을 정한 후 별도로 `턴 종료`를 누른다.
- 가계 활동: 여러 가게·카테고리의 상품을 담고 결제한다. 라운드 합계 6개 제한은 여러 번 결제해도 유지된다. 별도 `턴 종료`로 참여를 마친다.
- 남은 장바구니는 결제하거나 비워야 종료할 수 있다. 자신의 턴을 끝내면 추가 결제는 차단되며 다른 참가자가 끝날 때까지 지도를 둘러볼 수 있다.
- 가게도 기업이라는 설명과 활동 명칭을 사용한다. 생산 기업과 판매 기업의 자산·재고를 합치지는 않는다. 자기 거래 금지도 유지한다.

## 결제 규칙

- 담기는 재고 예약이 아니다. 서버가 현재 재고·운송비 포함 가격·예산·소유자·라운드·턴 종료 여부를 재검증한다.
- 한 항목이라도 품절/가격 변경/예산 초과이면 전체 결제를 거절한다. 부분 구매나 자동 대체 구매를 하지 않는다.
- 거래를 복제 상태에서 검증·적용하고 성공 시에만 실제 상태에 반영한다. 실패 시 임대료·광고비·생활비 지급도 반영되지 않는다.
- 같은 `requestId` 재전송은 저장된 영수증을 반환한다. 응답이 불확실한 UI는 동일 주문의 결과를 재확인한다.
- 가게 고정비·업종 변경·광고, 가계 생활비·주거비는 라운드당 한 번 처리한다. 만족도는 반복 구매분을 합산해 계산한다.
- 새 UI는 기존 우선순위·자동배분을 사용하지 않는다. 기존 제출 API와 자동 시뮬레이션은 하위 호환을 위해 유지한다.
- 즉시 결제한 학생 구매는 NPC의 턴 마감 처리보다 먼저 확정된다. NPC의 기존 생산·가격·수요 계산은 유지한다. 과거의 가상 NPC 진입 시각으로 이미 확정된 거래를 되돌리지 않는다.

## 동기화와 저장

- 학생·교사 상태 조회는 5초 간격이며 앞선 조회가 진행 중이면 새 조회를 보내지 않는다. 5초는 요청 주기이며 응답 지연까지 포함한 반영 시간 보장은 아니다.
- 새 온라인 수업의 자동 제출 마감은 기본으로 꺼져 있다. 교사가 명시적으로 타이머를 켜거나 강제 진행하면 기존 교사 제어가 적용된다. 기존 저장 수업의 설정은 유지된다.
- Apps Script는 기존 스크립트 잠금 안에서 읽기→검증→쓰기 작업을 수행하고, 잠금 해제 전에 Sheets 쓰기를 flush한다.
- 갱신 버전과 턴 제출 상태를 결제 영수증·게임 상태와 함께 저장한다. 라운드 도중 회계 누적치도 복원하여 반복 요청·재접속으로 비용이나 정산이 누락되지 않게 한다.
- 바뀌지 않은 조회 결과는 다시 저장하지 않는다. 40,000자를 넘는 저장 스냅샷은 `LiveStateChunks`에 분할하고 완료된 청크 목록을 마지막에 공개한다. 기존 단일 셀 저장은 계속 읽을 수 있다.

## 적용과 검증 범위

- 로컬, Node HTTP, Apps Script 공통 경제 엔진과 구매 화면을 수정했다.
- 프런트엔드 배포와 함께 Apps Script의 새 `dist/apps-script/Code.gs.js`도 새 배포 버전으로 반영해야 한다. 기존 `/exec` URL은 배포 업데이트 방식에 따라 유지할 수 있다.
- 실제 Google 계정에 배포하거나 GitHub에 push하지 않았다. 새 수업을 만들어 확인하는 것을 권장한다.
- 테스트: 중복 요청, 마지막 재고 경쟁, 전체 결제 거절, 타인 계정 구매 차단, 반복 구매 한도·비용, Sheets 복원·분할 저장 실패, 1/5/20명 7라운드 장바구니 진행. 실제 Google 서비스의 학급 동시 접속 지연·할당량은 배포 후 별도 확인해야 한다.

## 2026-10-02 경영 정보 개선

- 가게 턴의 첫 화면에 직전 라운드 매입·매출·손익 보고서를 표시하고 비서 의견을 다시 제공한다.
- 기업·가게의 남은 재고에 실제 생산/매입 시점의 수량 가중평균 원가를 기록한다. 가게 원가는 운송비 포함, 고정비 제외다. 기존 저장 재고의 알 수 없는 원가는 추정하지 않는다.
- 가계는 이번 턴 실제 구매 가격을 표시하며, 상품 추가 및 장바구니의 예상 만족도는 기존 평균 품질·필수 소비 감점·누적 점수 공식을 그대로 사용한다.
- 거래 기록은 학생의 최근 구매 라운드만 보관하고, 서버 결과가 아직 도착하지 않은 결제는 갱신 중임을 안내한다.
