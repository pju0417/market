# ROUND_FLOW.md

## 라운드 내부 순서 (고정, 임의 변경 금지)

1. 전원 기업 턴 수행
2. 기업 턴 결과 확정
3. 도매시장 갱신
4. 전원 가게 턴 수행
5. 가게 턴 결과 확정
6. 소비시장 갱신
7. 전원 가계 턴 수행
8. NPC 소비자 행동 처리
9. 라운드 종료 계산
10. 라운드 결과 발표
11. 다음 라운드 시작

같은 역할의 턴은 전원이 동시에 수행한다. 특정 학생이 다른 학생의 턴 종료를 기다리는 구조를
만들지 않는다 (동시 턴 처리는 [MULTIPLAYER_DESIGN.md](MULTIPLAYER_DESIGN.md) 참고).

## 7라운드 커리큘럼 (세부 밸런스는 조정 가능, 구조는 유지)

| 단계 | 내용 |
|------|------|
| 사전 단계 | 창업 준비: 기업 등록/분야 선택/위치 선택, 가게 등록/업종 선택/위치 선택, 기본 비용 확인 |
| 1라운드 | 첫 생산과 첫 거래 (인건비·임대료 등 기본비용은 이미 존재) |
| 2라운드 | 수요와 공급 변화 경험 |
| 3라운드 | 비용과 이익 구조 심화 |
| 4라운드 | 사업 확장: 신상품, 연구개발, 신규설비, 신규 점포 |
| 5라운드 | 경쟁 전략: 가격, 품질, 상품구성, 전문화, 광고 |
| 6라운드 | 시장 변화: 원자재 가격 변화, 유행, 소비자 소득 변화, 지역 변화 |
| 7라운드 | 최종 전략 및 종합 결과 |

주의: 기본 비용(인건비/임대료)이 "3라운드부터 등장"하는 것으로 오해하지 않는다 — 1라운드부터
존재하며, 3라운드는 그 구조를 더 깊이 다루는 단계일 뿐이다 (D-009).

이 커리큘럼의 각 라운드 세부 밸런스(수치, 이벤트 확률 등)는 플레이테스트를 거쳐 조정될 수
있다. 다만 라운드 구조(단계 순서, 7라운드 총량)는 [DECISIONS.md](DECISIONS.md)의 D-013에
따라 임의로 바꾸지 않는다.
